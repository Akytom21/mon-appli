# Stratégie de monétisation

## Décision

- L'app reste **100% gratuite** pour tous les utilisateurs (patients et interprètes).
- Monétisation par **publicités discrètes via Google AdMob**.
- Implémentation différée : nécessite un **SIRET** (Tom) pour créer le compte AdMob/AdSense.

## Emplacements pubs prévus

- Bannière en bas des listes (missions, historique)
- Interstitiel après création de RDV — **max 1x par jour**

## Zones sans publicité

- Espace sourd/malentendants (respect accessibilité)
- Messagerie
- Urgences SOS
- Transcription
